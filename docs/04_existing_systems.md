# Existing System Comparison

## Method

Four services were reviewed using published product/help pages on 25 October 2026. The comparison describes advertised features, not a controlled quality or completeness test. Features can vary by account, location, and product update. “Unknown” means the reviewed official source did not establish the feature.

## Findings and product decision

Generic vacancy search is not a sufficient differentiator: Enbek already aggregates sources and includes student practice workflows; other major services offer extensive filters or recommendations. The candidate product value to validate is a coherent student-first path that normalizes the early-career attributes, highlights freshness and original source, makes saved opportunities easy to compare, and explains a transparent fit indicator. This value proposition remains a hypothesis until the team interviews users and runs comparative tasks.

## Limits of this comparison

This is a desk review of official descriptions, not a feature-by-feature account-based audit. It does not compare number of live listings, ranking accuracy, inclusion, employer quality, fees, or job-seeker outcomes. Before final defense, record the same dated search scenarios, filters used, result counts, and observed limitations for each accessible platform.
